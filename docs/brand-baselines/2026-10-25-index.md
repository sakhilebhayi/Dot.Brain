# Brand experience baselines: cross-repo index, 2026-10-25

> **Advisory. Written by an AI session. Nothing here is ratified.** First baseline of the public UI repositories from the Brand Feeling Engine ([ADR-0021](../../adr/ADR-0021-brand-feeling-engine.md)), engine 0.3.0, rubric bxqs 1.0.0, shared draft profile `dot-ecosystem@0.1.0`. Each row links to the pull request that adds `brand/assessment/` to that repository; the score numbers are copied from the engine's own report.

**How to read the scores.** These are *automated static checks only*: no rendered pages, no expert assessment, no observed behaviour, no customer feedback. The most this kind of evidence can reach is a ceiling of 62.2 out of 100, and every check that could not run counts as zero. A score in the low teens therefore says "the source shows little of what the rubric looks for", not "the product feels bad". Scores this close together (8.62 to 14.8) cannot rank products; they show where the checks fire. No repository is above `not_ready`, and none can reach `release_ready` before observed or customer evidence exists.

## Limits and next steps

- **Phase 2** (product profiles from interviews with the owner) and **Phase 5** (observed and customer evidence) are what can move these numbers meaningfully. Nothing in this index substitutes for either.
- Static findings can be false positives (a label in another file, a template never mounted). Each report names the file and line.
- The rubric proposal BRP-2026-10-24 (detector ceiling and third-party origins) is still `proposed`, not ratified.
